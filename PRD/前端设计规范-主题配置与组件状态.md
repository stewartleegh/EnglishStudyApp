# 前端设计规范 —— Tailwind/shadcn 主题配置与组件状态

> 依据：《教学APP开发需求规格书 v2.4》§6/§7（IX-0～IX-5、DT-1～DT-7）+ project_rules §6。
> 定位：W1 脚手架任务 T-0115 的直接输入；本文件是设计 Token 的**唯一可执行落地源**，视觉预览见同目录《风格稿-style-guide.html》。
> 红线复述：仅浅色模式；唯一强调色 `#2E7D6B`；禁止新增强调色、渐变、徽章/奖杯式游戏化元素；功能色（错误/警示）仅用于文字与图标，不作装饰。

## 3. 组件状态规范（全部组件必须实现五态）

### 3.1 通用状态矩阵

| 状态 | 规范 | Tailwind 实现 |
|---|---|---|
| default | 按 Token 基础样式 | — |
| hover | 主按钮底色 → `accent-hover`；幽灵按钮底 → `accent-subtle`；卡片/列表行 → `accent-subtle` | `hover:bg-accent-hover` |
| active/pressed | 主按钮底色 → `accent-active`；scale 不变（不用弹性动画） | `active:bg-accent-active` |
| focus-visible | 2px `ring` 强调色 + 2px 白偏移（无障碍底线 G-2） | `focus-visible:ring-2 ring-ring ring-offset-2` |
| disabled | 透明度 40% + 禁止点击 + `cursor-not-allowed`；**禁止仅靠灰色文字表达禁用** | `disabled:opacity-40 disabled:pointer-events-none` |
| loading | 按钮内文字换为 Lucide `Loader2` 旋转 + 原宽度保持；区块级加载用骨架屏（§3.4）；**AI 反馈骨架屏 ≤10s（IX-2）** | `animate-spin` / `animate-shimmer` |

### 3.2 按钮（Button，4 个变体 × 5 态）

| 变体 | 用途 | 样式 |
|---|---|---|
| primary | 主操作（提交/入档/完成本单元） | `bg-accent text-accent-foreground hover:bg-accent-hover active:bg-accent-active`，圆角 4px |
| secondary | 次操作（重录/稍后再来） | `bg-card text-foreground border hover:bg-accent-subtle` |
| ghost | 弱操作（收起/跳过） | `text-muted-foreground hover:text-foreground hover:bg-accent-subtle` |
| link | 行内操作（查看解析） | `text-accent underline-offset-4 hover:underline` |

尺寸：默认高 44px（`h-11 px-4`），移动优先；dense 行内按钮最小 36px 仅限桌面管理端。
录音/录像/提交按钮：底部固定（`fixed bottom-0 inset-x-0` 安全区 padding `env(safe-area-inset-bottom)`），宽撑满，高 ≥48px。

### 3.3 表单（Input / Textarea / Select / 选项）

- 输入框：`border rounded-sm px-3 h-11`（多行 `min-h-24`），focus 同 §3.1 环；
- 错误态：边框与提示文字 `danger`，提示文字 `text-small` 置输入框下方；
- L2 选择题选项：整行可点（≥44px），选中态 `bg-accent-subtle` + 左侧 2px 强调色竖条；
- 勾选清单（操作清单/自评 checklist）：整行可点，勾选后文字 `text-muted-foreground` + 打勾动画（check 图标 150ms 淡入，不用五彩纸屑类动效）。

### 3.4 骨架屏与加载

- 骨架块：`bg-muted rounded-sm animate-shimmer`，配 200px 渐变扫光（`linear-gradient(90deg, transparent, rgb(255 255 255 / .6), transparent)`）；
- 页面级：最多 3 个骨架块模拟最终布局，禁止全屏转圈；
- AI 反馈卡骨架：分数条 + 2 行文字块，超 10s 自动切换"反馈稍后送达"降级文案（NFR-2）。

### 3.5 空状态（Empty State）

固定结构（垂直居中，最大宽 320px）：
1. Lucide 图标 20px，`text-muted-foreground`；
2. 一句说明（`text-small text-muted-foreground`，如"今天没有待复习的词卡"）；
3. 可选主操作（secondary 按钮，如"去逛逛课程地图"）；
**禁止**仅一句"暂无数据"，禁止插画/表情符号堆砌。

### 3.6 错误与降级态

- 区块错误：`danger-subtle` 浅底 + `danger` 图标文字 + 重试 ghost 按钮；
- AI 反馈失败：不显示红色错误页，固定文案"反馈稍后送达，不影响过关"+ 中性卡片（NFR-5）；
- 视频失效：静默切备选 + 一条 `text-small` 提示"已为你切换备选视频"（FR-3.6）；
- toast：右下角（移动端底部安全区上方），成功用强调色图标、失败用 danger 图标，停留 3s。

### 3.7 业务组件规格（对齐 IX/FR）

| 组件 | 规格要点 |
|---|---|
| AI 反馈卡（IX-5） | 固定顺序：三维分数条（accent 单色深浅三色阶：100%/65%/35% 透明度，不用红色）→ 亮点句（`bg-accent-subtle` 高亮）→ ≤3 改进点（各带示范改写，编号列表）→ 底部"这条反馈有用吗 👍/👎"（ghost 按钮，投后锁定） |
| 词块卡（FR-4.1） | 翻转卡：正面语块 + 发音按钮（Lucide Volume2），背面释义 + 例句 + 单元出处；底部三档自评按钮（陌生/模糊/掌握——仅用文字 + accent 选中态，**不用红黄绿灯**） |
| 进度状态（DT-7） | ○◐● 三态图标（Lucide Circle / CircleDot / CheckCircle2），单元行右端"2/6"计数用 `text-small text-muted-foreground` |
| 素养线标签 | 灰底小标签（`bg-muted text-muted-foreground rounded-sm text-tiny`）：乐理/风格/创作——不给三条线各配颜色 |
| 打卡热力图 | 自绘格子：无打卡 `#E5E5E5` → 有打卡用 accent 25%/50%/75%/100% 四档透明度 |
| 录像中状态 | accent 呼吸圆点（`animate-breath`）+ 计时，剩余 30 秒时计时文字转 `warning` |
| 成长曲线 | Recharts 折线统一 accent 单色；U1 基线参考线用 `muted-foreground` 虚线；页脚固定文案"AI 评分为学习反馈参考，非权威语言测评"（`text-tiny text-muted-foreground`） |
| 写作 diff | 删除：`line-through text-muted-foreground`；新增：`bg-accent-subtle`；不用红绿双色 |

## 4. 布局栅格与页面骨架

- 内容最大宽度：移动全宽（`px-4`），桌面居中 `max-w-2xl`（672px，阅读友好）；
- 关卡页统一骨架（§7.3）：顶部任务卡（可折叠，`sticky top-0`）→ 中部主操作区 → 底部固定操作栏；
- 卡片：`bg-card rounded-md p-4`，间距 `space-y-3`；页面区块间距 `space-y-6`；
- 分隔用 `border-b` 细线，不用投影堆层级；浮层（释义卡/记一笔浮层）才允许 `--shadow-pop`。

## 5. 无障碍与动效红线

- 对比度：正文/背景 ≥4.5:1（#191919/#FFFFFF、#737373/#FFFFFF 均达标）；accent 白字按钮 4.6:1 达标；
- 所有可点元素 ≥44px 且 `focus-visible` 可见；录音/录像/提交按钮必须有 `aria-label`；
- 动效总时长 ≤200ms，仅 fade/slide；`prefers-reduced-motion` 下关闭 breath/shimmer 动画（用 `@media (prefers-reduced-motion: reduce)` 兜底）；
- 禁止：深色模式切换、渐变色块、玻璃拟态、徽章/奖杯/排行榜元素、红黄绿评价色。
