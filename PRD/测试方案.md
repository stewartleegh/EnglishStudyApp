# 测试方案（单元测试 + 集成测试 + E2E）

> 目标：把 SRS §10 验收标准（AC-01～AC-11）逐条转化为可自动执行的测试。
> 原则：**LLM 永不进 CI 真调**——所有 AI 链路用 fixture/录制回放测试；真模型只在 golden 回归（手动触发）中调用。
> v2.2 同步：新增问答系统（AC-11/E9）、监护人链路删除流（AC-10/E10）、媒体上传限流（QUOTA-5）、前端错误上报（NFR-5/API-19）、北京时间日界（NFR-8）的覆盖。
> v2.3 同步：部署架构由双模式（Vercel 云 + 本地）改为纯本地（Docker Supabase + node + mkcert），E6/E8 更新为本地部署实测。
> v2.4 同步：单用户模式，移除注册/认证/监护人链路；E1 起点改为知情同意页；E10 废止；guardian API 集成测试移除；AC-10 废止。
> v2.4 复审补丁（2026-09-02）：① §1/§3.2 RLS 用例改为固定 user_id 过滤验证（原双用户 JWT 交叉验证废止）；② §3.1 两处"未认证 → 401"用例废止（无认证）；③ E4 配额豁免口径对齐 QUOTA-4（seed role=test）；④ quiz/submit 追加 answer 不下发前端断言。

## 1. 测试金字塔与技术选型

| 层 | 工具 | 覆盖目标 | 占比 |
|---|---|---|---|
| 单元测试 | Vitest + React Testing Library | lib/ai 全模块、状态机、工具函数、关键组件 | 60% |
| 集成测试 | Vitest（API Routes + supabase 本地实例）+ MSW | API 契约、DB 迁移与 RLS、导入脚本、清理任务 | 30% |
| E2E | Playwright（chromium / webkit 双内核 + 移动设备模拟） | §10 验收标准主链路 | 10% |
| LLM 契约回归 | 自研脚本（golden 样本集 20 条，手动/周触发） | prompt 模板变更无回退 | 按需 |

- **Mock 策略**：`@ai-sdk/deepseek` 用 MSW 拦截 HTTP 层，返回 fixture JSON（含合法/非法两种）；Whisper 兼容服务同理。
- **DB 策略**：`supabase start` 起本地实例，迁移文件全量回放后跑测试；RLS 验证**固定 user_id 过滤**（v2.4 单用户：仅 seed 学生 ID 可读写，非种子 ID 写入与匿名读取均被拒——替代原双用户 JWT 交叉验证）。
- **覆盖率门槛**（写进 CI）：`lib/ai/**` ≥ 90%，`app/api/**` ≥ 80%，`lib/**` ≥ 75%，整体 ≥ 70%。

### 2.1 lib/ai（P0，覆盖率 ≥90%）

| 用例 | 断言 |
|---|---|
| provider 固化参数 | 生成的调用配置恒含 `thinking: {type:"disabled"}`（防 I-1 回归） |

### 2.5 lib/time（v2.2 新增，NFR-8）

| 用例 | 断言 |
|---|---|
| beijingDayStart 固定偏移 | 任意时刻计算结果 = UTC+8 当日 0 点换算回的 UTC 时刻；**强制模拟服务器本地时区为 UTC 与非 UTC 两种环境，结果不变**（禁用本地时间的核心断言） |

## 5. LLM Golden 回归（防 prompt 回退）

- **样本集**：`evals/golden/` 下 20 条真实形态输入（口语 10 条：含短沉默多、跑题、优秀三档；写作 10 条：含语法点错误、中式英语、优秀三档），每条带人工标注的期望分数区间与必须命中的改进点。
- **运行**：`pnpm eval:golden --prompt speaking_eval.v2` 真调 API（手动触发，产出计入成本），输出对比报告：分数漂移、schema 通过率、必中点命中率。
- **门槛**：schema 通过率 100%、分数漂移 ≤1 分、必中点命中率不下降 → 才允许 `prompt_templates.active` 切换。
- **频率**：每次模板变更必跑；无变更时每周随抽检（SRS §5.5）跑一次保持基线。

## 6. CI 编排建议

```yaml
jobs:
  unit:        # pnpm test:unit（Vitest，无网络）
  integration: # services: supabase local；pnpm test:integration（MSW mock 外部）
  e2e:         # pnpm test:e2e --project=chromium；webkit 项目 nightly 跑（省 CI 时长）
  gates:
    - coverage: lib/ai ≥90%, app/api ≥80%

# eval:golden 不进 CI，workflow_dispatch 手动触发
```
